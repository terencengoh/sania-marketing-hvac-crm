# Sania Marketing HVAC CRM

Client-side web application for managing HVAC leads, clients, jobs, quotes, and recurring maintenance reminders.

## Features
- Lead, client, job, and quote management
- Photo notes
- Recurring maintenance reminders
- Dashboard with stats and search/filter
- Calendar view
- Dark mode
- CSV export
- Data stored in browser localStorage

## Usage
1. Download or clone this repo
2. Open `index.html` in a browser
3. All data stays local to your browser

Built for Sania Marketing.
